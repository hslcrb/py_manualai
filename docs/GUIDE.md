# ManualAI 상세 이용 가이드 (User Guide)

ManualAI(Obedor)를 200% 활용하기 위한 상세 가이드입니다.

---

## 🔍 기본 검색 (Basic Search)
`main.py`를 실행한 후, 검색창에 원하는 키워드를 입력하세요.
- **키워드 매칭**: `파이썬`, `비트코인` 등 핵심 단어 위주로 검색할 때 가장 높은 정확도를 보입니다.
- **문장 검색**: `김치찌개 끓이는 법`과 같이 자연어 문장을 입력해도 유사도 기반으로 관련 문서를 찾아줍니다.

---

## 💡 검색 팁 (Power User Tips)

### 1. 하이라이팅 확인
검색 결과 본문에서 내가 입력한 단어가 강조되어 표시됩니다. 이를 통해 검색 결과가 왜 적절한지 시각적으로 빠르게 확인할 수 있습니다.

### 2. 연관 검색어 활용
검색 결과 하단에 표시되는 **[연관 검색어]**를 주목하세요. 이는 데이터베이스 내부에서 해당 단어와 가장 밀접한 연관성을 가진 다른 지식들입니다. 꼬리에 꼬리를 무는 지식 탐색이 가능합니다.

### 3. 계층 구조 파악
각 결과물 상단에 `[소주제/대주제 > 중주제]`와 같이 계층 정보가 표시됩니다. 내가 찾는 정보가 어느 카테고리에 속해 있는지 명확히 알 수 있습니다.

## 🛠️ 개발 및 성능 (Performance)

### 데이터베이스 재생성 (Migration)
데이터가 꼬이거나 최신 로직으로 다시 생성하고 싶을 때 사용하세요.
```bash
python3 src/migrate.py
```
*주의: 기존 `data/manual_ai.db` 파일이 삭제되고 새롭게 생성됩니다.*

### 대규모 데이터 처리
ManualAI는 100만 건 이상의 데이터도 처리할 수 있도록 설계되었습니다. 데이터가 많아질수록 초기 마이그레이션 시간은 늘어나지만, 검색 속도는 `SQLite Index` 덕분에 0.1초 미만으로 유지됩니다.

## 🐳 도커(Docker) 사용법

### 이미지 빌드
```bash
docker build -t manualai .
```

### 컨테이너 실행
```bash
docker run -it manualai
```
*도커 실행 시 내부에 포함된 `migrate.py`가 자동 실행되어 즉시 검색 가능한 상태가 됩니다.*
